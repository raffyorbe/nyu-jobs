Project Details
NYU Student Program Portals & System Design

I designed and implemented a system architecture to modernize the department’s manual administrative workflows, transitioning them from fragmented spreadsheets to a centralized, automated digital ecosystem.

  • Problem: The department relied on manual spreadsheet entry via Airtable for student hiring and program management. This created significant bottlenecks and lacked real-time transparency for applicants.
  • Solution: I developed a UI-driven portal architecture using Airtable as a relational backend. The system integrates automation logic to trigger email notifications, calendar invites, and document generation (contracts and work authorizations) based on real-time application status.
  • Outcome: While this UI was originally prototyped for student hiring, the system design was adopted as the foundational backend for the department’s global and research programs. It successfully scaled to support 1,000+ students, streamlining their application journeys and enhancing the overall student experience.
Key Contributions
  • Operational Automation: Automated the entire application and document creation lifecycle, significantly reducing manual administrative overhead.
  • Annual Cost Savings: Optimized information systems utilization and aligned requirements with operational strategy, reducing IT costs by 14.7% annually.
  • Enterprise-Grade Security: Implemented access management and cybersecurity policies, ensuring all portals are protected by 2FA via NYU email.
  • Scalable Architecture: Built a modular system that allowed the department to deploy unique portals across different programs while maintaining a unified, secure database structure.
